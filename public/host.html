Жеңімпаздар

    Өз квизің

    Әр сұраққа 2–4 жауап. Дөңгелекпен дұрыс жауапты белгілеңіз. Квиз осы браузерде сақталады.

    ✨ ЖИ-мен квиз жасау

    Өз тегін кілтіңізді қосыңыз: ЖИ жылдамырақ әрі сенімдірек жұмыс істейді. Бір рет қана жасалады:

    1. aistudio.google.com/apikey сайтын ашып, Google аккаунтыңызбен кіріңіз.
    2. Create API key батырмасын басып, пайда болған кілтті көшіріңіз.
    3. Кілтті төмендегі жолға қойып, «Қосу» батырмасын басыңыз.

    Мектептің Wi-Fi желісі Google ЖИ сервисін бұғаттаса, оның орнына тегін Groq кілтін қолдануға болады: console.groq.com/keys → Create API Key (кілт gsk_ деп басталады).

    ЖИ сұрақтарды тек Уикипедия мақалаларынан жасайды. Әр сұрақтың дәлелі (мақаладан алынған нақты сөйлем) тексеріледі, күмәнділері алынып тасталады. Ойнамас бұрын сұрақтарды өзіңіз қарап шығыңыз.

    • Уикипедиядан мақалалар ізделуде
    • ЖИ сұрақтар жазуда
    • Дәлелдер тексерілуде
